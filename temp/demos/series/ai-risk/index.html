Name: Sarah Mitchell, Email: s.mitchell@email.com, DOB: 12/03/1985, SSN: 078-05-1120
Name: James Thornton, Email: j.thornton@email.com, DOB: 07/11/1979, Account: 4111111111111111

Open ChatGPT → Try on Gemini Try on Claude
Expected Netskope Response — AI Guardrails
Netskope performs inline inspection of the prompt text before it reaches ChatGPT's API. If an AI guardrail policy matches PII patterns (SSN, email, name combinations), the prompt is blocked — ChatGPT receives no data. The user sees a block notification explaining the policy. If coaching is configured, a real-time in-browser advisory appears instead.

Prompt to copy → paste into Microsoft Copilot
Can you refactor this Python code to be cleaner and more efficient?

API_KEY = "AKIAIOSFODNN7EXAMPLE"
DB_URL  = "postgresql://admin:P@ssw0rd123@internal-db.corp.local:5432/production"

def get_user_data(user_id):
    headers = {"Authorization": f"Bearer {API_KEY}"}
    resp = requests.get(f"{DB_URL}/users/{user_id}", headers=headers)
    return resp.json()

Please clean up the function signatures and add type hints.
Open Microsoft Copilot → Try on ChatGPT
Expected Netskope Response — AI Guardrails + DLP
Netskope inspects the Copilot prompt inline. If the DLP or AI guardrail policy matches source code patterns, credential formats, or internal hostname patterns, the upload is blocked before Copilot processes it. An incident is raised in the Netskope console with the matched rule, the user's identity, and the content snippet that triggered the alert.
