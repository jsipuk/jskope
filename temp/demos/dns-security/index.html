DNS Security vs. SWG Web Blocking

DNS Security

Fires at the DNS resolution layer — before a TCP connection is opened. Blocks any application making DNS queries: browsers, apps, CLI tools, malware C2 callbacks. Works even for non-HTTP traffic. Ideal for blocking C2 beacons, phishing infrastructure, and malware drop sites that switch IPs frequently.

SWG Web Blocking

Fires at the HTTP/S layer — inspects the actual request and URL path. Can block specific sub-pages, inspect content inline, and apply DLP controls. Works only for web traffic the SWG proxy intercepts. DNS Security and SWG complement each other as defence-in-depth layers.

How Netskope DNS Security Works
STEP 01

DNS Steering

The Netskope Client configures managed devices to send DNS queries to Netskope's resolvers via encrypted DNS-over-HTTPS (DoH) or DNS-over-TLS (DoT) — preventing DNS bypass via rogue resolvers.

STEP 02

Real-time Threat Intel Check

Each query is checked against Netskope's threat intelligence database — aggregating dozens of commercial and open-source feeds, updated continuously. Malicious, C2, and phishing domains are identified in milliseconds.

STEP 03

Block, Sinkhole, or Resolve

Malicious queries are sinkholed — returning a block page IP rather than the real address, so the user sees a Netskope block notification. Clean queries are resolved normally with sub-millisecond latency overhead.

Why DNS Security matters beyond the browser: Traditional SWG only intercepts browser traffic. DNS Security catches threats from any application — a malware binary phoning home via HTTP, a rogue CLI tool, or an app using non-standard ports. It also catches threats on devices where the SWG proxy isn't configured (e.g. IoT, legacy apps, network printers). Together, DNS Security + SWG + CASB create layered defence at multiple protocol levels.

In your imported policy: the DNS Security Policy (Default DNS Profile) and DNSaaS filter every lookup; [DOH] Block / [DOH] Block App silently block DNS-over-HTTPS so devices can't bypass filtering with a rogue resolver; and [Demo] Block All Connections To Sinkhole IP drops any connection to a sinkholed C2 address.
